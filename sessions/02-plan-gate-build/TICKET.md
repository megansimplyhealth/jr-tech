# JR-102 — Make a new starter's first week in tech easier

|              |                         |
| ------------ | ----------------------- |
| **Type**     | Story                   |
| **Priority** | Medium                  |
| **Reporter** | Jr tech group           |
| **Assignee** | Your team               |
| **Estimate** | 25 minutes (one session) |

## Description

As a **new starter in tech**,
I want **something that helps me find my feet in my first week**,
so that **I feel useful sooner and don't have to ask the same questions everyone before me asked**.

Think back to your own first week: the acronyms, the tools, who to ask, what to set up, what "done" means here. Pick **one** of those problems and solve it well.

## Outcome needed

One small, finished thing a new starter could pick up and use on day one. What it is, is up to you — an app, an API, a document or something else. See [`SUGGESTIONS.md`](SUGGESTIONS.md) for ideas.

## Acceptance criteria

- It solves one clear first-week problem, and you can say which one in a sentence.
- A new starter could use it without you explaining it.
- It's finished enough to show in two minutes.
- You agreed the plan as a team before anything was built.

## Constraints

- Built with any AI tool in the browser — free tier and normal chat are fine.
- Nothing to install.
- No real company, customer or member information. Use made-up content.

## Out of scope

- Logins, databases, hosting or deployment.
- Covering everything a new starter needs. One problem, done well.
