# PR #530 — perf: reduce PayFast timeout 10s → 2s to free workers

**Opened:** Mon 14 Sep **Merged:** Tue 15 Sep

## Description

During INC-2250 our payout workers were stuck for 10s per call waiting on PayFast, so the whole
batch backed up. Dropping the timeout to 2s means we fail fast and the retry (added in #498)
kicks in sooner.

PayFast **staging** p95 latency is ~180ms (screenshot below) so 2s is >10x headroom.
